## ✅ Works in Multiplayer

**Here's how it works:**

- **Server has Descriptive installed** — your styled name is shown to everyone automatically, no extra setup needed.
- **Vanilla or unmodded server** — Descriptive will ask if you want to connect to an external relay server so other Descriptive users can still see your name. **This connection is opt-in**, you can enable this function in the **Descriptive Settings** > **Toggle Relay...** Menu.

## 📥 Getting started

### 🎮 Minecraft Client

1. Download **Descriptive** and the [Fabric API](https://modrinth.com/mod/fabric-api).
2. Drop it in your `mods/` folder
3. Boot up Minecraft
4. Launch a world, press `U` or type `/descriptive config` and go customize!

### 🖥️ Minecraft Server
1. Download **Descriptive**
2. Drop it in your server's `mods/` or `plugins/` folder
3. Start the server. You can allow or disallow players to use the mod in the `descriptive-server.toml` file

> ⚠️ Only download from [Modrinth](https://modrinth.com/plugin/descriptive). Don't trust random sites!
